# Rupiq V1 — Pilot

Static, local-first expense tracker for a 14-day family-and-friends pilot. Every expense can be recorded as cash, UPI, card, or bank transfer. Drop this folder or the accompanying ZIP into Netlify Drop. No build step, database, account, tracking, or server is required.

## Pilot guide

1. Open the site on each tester's own phone and complete onboarding.
2. Ask them to record every expense for 14 days, starting with 1–3 manual entries a day.
3. On day 7, ask: “What surprised you?” and “What felt slow or missing?”
4. On day 14, collect optional feedback in person or through your preferred form. Prioritise recurring friction over feature requests.

## Data and backup

All data stays in that browser via local storage. Use **More → Your backup → Export backup** before changing devices or clearing browser data. Restore it with the matching control. CSV imports require review and skip transfers, refunds and credit-card repayments to reduce double counting.
